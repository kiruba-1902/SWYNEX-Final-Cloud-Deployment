- Understanding static website hosting.
- Learning the basic cloud deployment workflow.
- Understanding how GitHub and Netlify work together.

| Challenge | Solution |
|---|---|
| Organizing project files | Used GitHub repository structure |

## 5. Best Practices Learned

- Maintain organized project documentation.
- Test the website after deployment.
- Review deployment logs regularly.
- Protect credentials and sensitive information.
- Monitor hosting usage and plan limits.
- Keep source code version-controlled.

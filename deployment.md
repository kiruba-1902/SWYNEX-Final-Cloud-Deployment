# CloudTask – Cloud Deployment Guide

## 1. Introduction

This document explains how the CloudTask static web application was deployed using GitHub and Netlify.

## 2. Technologies Used

- HTML
- CSS
- JavaScript
- GitHub
- Netlify

## 3. Source Code Repository

GitHub repository:

https://github.com/kiruba-1902/SWYNEX-Basic-Cloud-Deployment

GitHub is used to store and manage the application's source code.

## 4. Deployment Steps

### Step 1: Prepare the Application
- Develop the frontend using HTML, CSS, and JavaScript.
- Verify the website locally.
- Organize the project files.

### Step 2: Upload to GitHub
- Create a GitHub repository.
- Upload the application source files.
- Commit changes to the main branch.

### Step 3: Connect Netlify
- Log in to Netlify.
- Import the existing GitHub project.
- Select the correct repository.
- Configure the deployment branch as main.

### Step 4: Publish the Website
- Start the deployment.
- Wait for the production deployment to finish.
- Verify that Netlify reports the deployment as Published.

## 5. Live Deployment

**Hosting Platform:** Netlify

**Live Website:**

https://sensational-cucurucho-1bf736.netlify.app/

The published URL allows users to access the CloudTask application through a web browser.

## 6. Deployment Verification

The following checks are used:

- Open the live website.
- Confirm that the homepage loads.
- Test the task management interface.
- Check browser console for errors.
- Review Netlify deployment status.
- Inspect deployment logs.

## 7. Deployment Benefits

- Easy integration with GitHub.
- Automatic publishing when connected repository changes are pushed.
- HTTPS support.
- Deployment history and logs.
- Simple static website hosting.

## 8. Conclusion

The deployment process demonstrates how a frontend application can be hosted using cloud deployment services. GitHub provides source code management, while Netlify handles website hosting and publishing.
